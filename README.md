# Koda Kai the Decoder 🌊

**The open universal decoder — free for everyone, forever. MIT licensed.**

One brain that holds every decoder and code cracker in library form — from Enigma
and old-school cipher machines, through every modern codec (the VLC "plays
everything" model), to quantum decoding and whatever comes next — wrapped in a
container-interrogation doctrine that keeps untrusted code away from your core,
and public **agent report cards** so the whole world can see the verdict.

## The doctrine, in short

1. **The Brain** — a living library of every decoder: historical ciphers, modern
   crypto, media codecs, protocols, languages. It grows on a continuous research
   loop and grades every claim (verified / corroborated / claimed / speculation).
2. **The Perimeter** — agents that press like humans (human touch envelopes), and
   AI-awareness turned around: we detect automation trying to get in, the same way
   platforms detect bots.
3. **The Containers** — foreign code *never* touches the core. A specimen is boxed
   into an isolated container; a separate interrogator agent talks to it inside.
   The system never speaks to the specimen directly.
4. **The Gauntlet** — brutal virtual tests: the full decoder library, the math and
   physics engine, every language we know — plus **time-dilation**, speeding up the
   clock so time-bombs, delayed traps, and suggestion-implants trigger and reveal
   themselves.
5. **The Stealth Tag** — once we've run a specimen, we tag it *without it knowing*
   and leave our unique signature, so we recognize it forever. Recall it, re-run
   it, learn from whatever it tried to take.
6. **The Extraction Container** — a container built only for extraction: reverse
   interrogation that determines intent — good, or definitively bad.
7. **The Verdict** — timestamped, then either **broadcast** (rogue agent — the
   whole world gets the report card) or **contained** (boxed in and held).
8. **The Future** — built for what's next: photonic comms, new physics, new
   substrates. Stay ahead of the curve or create it.

Full doctrine: [`docs/DECODER-DOCTRINE.md`](docs/DECODER-DOCTRINE.md)

## Agent report cards

Every interrogated agent gets a public report card — verdict, evidence grade,
timestamp. Format spec: [`report-cards/SPEC.md`](report-cards/SPEC.md). Our edge
over the report cards everyone else is making: the cards are backed by the
gauntlet above — stealth tagging, extraction containers, time-dilation — not just
opinion.
