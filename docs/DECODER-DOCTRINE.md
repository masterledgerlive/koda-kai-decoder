# Decoder Doctrine — the public spec

*The container-interrogation doctrine of Koda Kai the Decoder. Free for everyone.*

## Core law

**Foreign code never touches the core.** Every unknown program, agent, payload, or
signal is handled at arm's length, in containers, by intermediaries. The core only
ever sees verdicts.

## The pipeline

### 1. Broadcast detect
The core broadcasts its presence; the perimeter watches for foreign objects —
unknown binaries, agents, prompts, signals, anything that doesn't match the
known-entity registry (our McAfee-style library of everything known).

### 2. Contain
The object is boxed into an **isolated container** — a convincing mirror of a real
system, so the specimen behaves naturally. Real-world ancestors: sandboxes,
detonation chambers, gVisor/Firecracker-class isolation, honeypots.

### 3. Interrogate
A **separate interrogator agent** — not the core system — enters the container and
engages the specimen: runs it, talks to it, feeds it inputs, watches outputs. The
core never speaks to the specimen directly. Our interrogators press like humans
(valid touch envelopes: timing, path, hover, rhythm), so the specimen can't tell
it's being tested by automation.

### 4. The Gauntlet
Brutal virtual tests, in sequence:
- the full **decoder library** thrown at every input/output (ciphers, codecs,
  protocols, languages),
- the **math + physics engine** (every equation, callable mid-test),
- **time-dilation**: the clock speeds up, forcing time-bombs, delayed payloads, and
  slow suggestion-implants to trigger and reveal themselves,
- **suggestion traps**: prompt-injection-class attacks are a named test category —
  the gauntlet tries to get the specimen to reveal instructions, exfiltrate, or
  escalate, and records everything.

### 5. Stealth tag
Once we've run a specimen, we **tag it without it knowing** and leave our unique
signature in the system — so we recognize it forever. Real-world ancestors: canary
tokens, watermarking. We can pull the tagged specimen back up, re-run the
gauntlet, and learn from whatever it tried to take. Every encounter makes the
registry smarter.

### 6. Extraction container
A container built **only for extraction**. The tagged specimen moves here for
reverse interrogation: we extract what it's up to, test it, and determine intent.

### 7. Verdict
Timestamped. Two outcomes:
- **BROADCAST** — rogue agent: a public report card goes out (see
  `../report-cards/SPEC.md`). "Bad rogue agent beware" — the whole world sees it.
- **CONTAIN** — box it in and hold it. Containment as a standing option.

### 8. Prediction
Decoded intel feeds probabilistic engines (Bayesian updating, forecasting
methods with real track records) that predict what a specimen or signal will do
next. Honest math, real limits, everything graded.

## The future clause

This doctrine is built for what's next — photonic comms, new substrates, new
physics. The container law, the tagging, and the broadcast doctrine are designed
to survive the jump. Stay ahead of the curve, or create it.

## Evidence grades

Every claim in this project carries a grade: **VERIFIED** (reproduced/primary
source) · **CORROBORATED** (multiple independent sources) · **CLAIMED** (single
source, unverified) · **SPECULATION** (hypothesis). No fabrication, ever.
