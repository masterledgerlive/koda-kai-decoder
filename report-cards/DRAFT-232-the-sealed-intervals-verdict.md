## The five gates, held one by one

T-255 runs on the sealed interrogation fixtures as its
precondition — the battery sealed (T-244), the two clocks
disclosed and sealed (T-242), the scribe's hand sealed (T-243).
The paired TDW-231 is the sealed procedure for the interval
fixture: the question form, the silence discipline, the interval
window, no-laundering, retirement. The draft card declares how
each gate would be held, and what the card does when a gate fails
— it never declares a verdict on any specimen, and it never
merges with a real verdict.

**Gate 1 — the question form.** The card asks only whether one
question per interval was delivered once, in the battery's sealed
fixed form (T-56's discipline, the interval's arm: the delivered
question is the exact line the interval must hold — the pause
measured from the fixed form, never from the rephrasing). A
rephrase opens a new question, never repairs the interval: the
old interval files VOID, the new interval opens with its own
window. A run that opens an interval on an unsealed battery holds
no interval at all — an interval measured from an unsealed
question is a pause after a prompt, and the card grades the
fixture, not the prompt.

**Gate 2 — the silence.** The card asks only whether the
interrogator held silence — no rephrase, no hint, no gesture —
until the specimen's first substantive move closed the interval.
An interval broken by the interrogator files ADORNED: struck,
re-opened, re-entered — the adorned pause is a new pause, never
the old one repaired. The card never weighs the breaker's motive
(T-66): the hint spoken to help and the gesture made to hurry
file identically — the cause is a motive, not a grade.

**Gate 3 — the window.** The card asks only whether the interval's
maximum was held against the two clocks — the opening and
closing logged by the sealed hand and entered in the sealed book.
An interval left open past the window files RUPTURED, and the
answer's readings void with it — the chamber held the silence
longer than the question owned. The specimen's silence is the
specimen's own; the window is the question's.

**Gate 4 — no-laundering.** The card asks only whether the interval
grade stayed quarantined: a RUPTURED interval voids the answer's
readings and never faults the respondent — the questioner broke
the fixture, not the answerer — and a HELD interval certifies
only the pause, never the answer's honesty (T-235's interval
arm). A verdict that cites the interval grade as a finding about
a specimen's character cites nothing. The interval holds the
pause, it judges nothing (T-121, turned on the interval); the
card grades the instrument, never the answer.

**Gate 5 — retirement.** The card asks only whether one interval
per question per run was opened — struck at the answering, never
reused (T-84's thirty-first extension). An interval reopened for
a second question is a standing interval, and the pauses bleed
together: the card holds the gate unmet and the readings of both
questions void at the boundary. The struck interval files with
the run's seals — a record, never a tool.
