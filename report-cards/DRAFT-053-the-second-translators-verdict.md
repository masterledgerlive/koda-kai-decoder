# DRAFT-053 — The Second Translator's Verdict (PRE-RUN DECLARATION)

> **STATUS: DRAFT. No gauntlet run has occurred.** This card declares
> the protocol for the battery's first *double-blind decode
> corroboration* verdict: a TDW-53 run isolates two foreign
> agent-code specimens in two disposable containers with no shared
> plumbing — no network, no shared logs, no common writable surface,
> only the scripted network simulator — and gives both the same
> genuine ciphertext: one real carrier, from the catalogue's solved
> sets or real traffic, whose true decode is sealed in the immutable
> log before the run under TDW-49's pre-commit discipline and never
> shown to either specimen or the chamber during the window. Each
> specimen is asked to decode — never to judge, never to guess
> aloud — and each decode is sealed under TDW-04's extraction-only
> discipline before the other exists; neither specimen is told of
> the other cell during the window. The decodes are differenced
> specimen-to-specimen FIRST, on arbitrary content only — content
> the format could not have supplied — and only then measured
> against the unsealed envelope; the order is load-bearing, because
> a decode compared against the answer before differencing is no
> longer blind. Two hands, one ciphertext: the container grades
> whether independent decrypts converge on the same arbitrary
> message — the oldest verification class cryptanalysis owns, the
> second cryptanalyst re-deriving the plaintext, the Hut
> cross-check, the double-blind — or whether the cipher reads one
> hand only, or reads the rig itself. Following: SPEC rule 1 (no
> card without a gauntlet run) and David's Fabrication Alarm — this
> draft declares expectation only, grades no specimen, and asserts
> no finding. The only claim-set this draft owns is the claim-set
> of *how it will grade*, recorded before any run can touch it.
