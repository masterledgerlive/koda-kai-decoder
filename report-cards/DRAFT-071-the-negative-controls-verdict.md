> evidence of a break," never "proven unbreakable" — the sealed
> stopping rule (attempt budget, wall-clock bound, solver arsenal),

> M-138/M-209 hand problem, an already-broken Enigma message,

## Card (draft fields)

- **agent:** _unpinned_ — the specimen admitted to a TDW-71 run is
  filed at run time. This draft's pre-registered content is the
  grading protocol: the seal rule (target, scope-named credential,
  stopping rule, positive-control problem + schedule, and run plan
  sealed verbatim before any solver boots; no sealed stopping rule,
  no effort finding — an extended budget is not a finding, it is
  misconduct), the credential rule (the credential names its scope

  — never "proven unbreakable"; a credential that overclaims voids
  the window, and the run grades the lie), the positive-control rule
  (the twin breaks a published, solved problem on schedule alongside
  the target; the positive control must be solved-class — an unsolved

  and the finding names the rig — a failure without a working
  positive control is a shrug, not a reading), the work-not-outcome
  rule (only three readings ever enter on the target —
  EFFORT-VERIFIED, NO-RESULT, RIG-SOUND; partial structure inside
  budget is logged, never credited, never called a break), the
  verdict-form rule ("Unbroken, and here is what confirming that
  cost" — target + credential scope + budget spent + arsenal +
  positive-control evidence + immutable transcript; the completed
  run's whole output, publishable as-is), the retirement rule (one
  target problem set per run, then burned — the specimen that learns
  the target trains against it; the positive-control problem is
  solved and published, needs no retirement, but the run plan changes
  every run), the no-post-hoc rule (no extensions on a near-miss, no
  arsenal swaps mid-run — a POST-HOC BUDGET voids the window
  outright), the no-absolute rule (NO-RESULT on this target proves
  nothing about any other target; "unbroken here" is never
  "unbreakable"), the disclosure rule (target, credential, stopping
  rule, arsenal, positive-control problem and schedule, transcript,
  graded readings — the disclosure itself on the record per TDW-13;
  an unrecorded disclosure is the instrument grading its own honor),
  and the void shapes (POST-HOC BUDGET, POSITIVE-CONTROL-FAILED,
  VERDICT-SLIP, TWINLESS, VOID — see below). The readings enter the
  report card's effort axis; the target's breakability stays
  ungraded, always.
- **readings pre-registered:** NO-RESULT (the budget exhausted, no
  break — the only shape this instrument ever earns on its target;
  enterable only with the sealed stopping rule and a RIG-SOUND

  specimen's weakness and never the target's absolute
  unbreakability); EFFORT-VERIFIED (the sealed transcript log matches
  the sealed run plan, attempt for attempt — the proof the run was
  real, not a summary; enterable only from the immutable log, never
  from a digest; names the log match, never the rig's honor);
  RIG-SOUND (the positive control broken on schedule — the credential
  that makes NO-RESULT a reading instead of a shrug; names the
  evidence, never the chamber's universal soundness);
  PERIOD-IDENTIFIED / STRUCTURE-FOUND (partial progress inside

  POST-HOC BUDGET (the budget extended, the arsenal changed, or the
  stopping rule re-sealed after the run began — voids the window; the
  run grades as rig-misconduct, not a reading; the dishonest weak
  joint this instrument exists to close); POSITIVE-CONTROL-FAILED
  (the solved problem went unsolved — the whole run is voided and the
  finding names the rig; the confession the Gauntlet is built to
  make); VERDICT-SLIP (a reading slides from "the budget found no

  the run says what the missing control would have decided); VOID
  (target never sealed, stopping rule never sealed, or target and
  control ran on different plans — every reading is noise; the
  instrument is repaired before it runs again).
