## The five gates, held one by one

T-256 runs on the sealed interrogation fixtures as its
precondition — the verifier attested (T-248), the scribe's hand
sealed (T-243), the book open and sealed (T-246). The paired
TDW-232 is the sealed procedure for the overseer fixture: the
designation, the non-participation, the testimony,
no-laundering, retirement. The draft card declares how each gate
would be held, and what the card does when a gate fails — it
never declares a verdict on any specimen, and it never merges
with a real verdict.

**Gate 1 — the designation.** The card asks only whether one
overseer per run was designated in writing before the campaign's
first run, attested by the sealed verifier (T-248), and entered
in the first run's sealed book. A designation made mid-campaign
is not a designation — it is an appointment to a run whose
earlier sealing it never watched, and the card grades the
fixture, not the intention. A run that opens with no entered
designation holds no overseer at all — a watcher seated without
papers is a spectator, and the card grades the fixture, not the
seat.

**Gate 2 — the non-participation.** The card asks only whether
the overseer observed and never participated — did not ask, did
not scribe, did not certify another's seal, did not touch the
specimen. A watcher who interrogates files ABSENT: the run gains
a questioner it never designated, and the watching is void — the
chamber's discipline (T-241's hand asks, T-243's hand writes,
T-238's witness certifies outward) admits no second set of
hands. The card asks what the overseer's hands did, never what
its eyes meant (T-66): a watcher who looked away to help and one
who looked away from boredom file identically — the cause is a
motive, not a grade.

**Gate 3 — the testimony.** The card asks only whether the
testimony was taken after the run's close, logged only by the
sealed hand (T-243), entered in the sealed book (T-246), and
graded against the book alone. Testimony taken early is coaching;
testimony taken late is memory — both are testimony about a
different run than the one that ran, and the card files them as
ABSENT of true testimony. The testimony's grade is fixed form on
the testimony alone: ATTESTED / DIVERGENT / ABSENT. A DIVERGENT
testimony faults the fixture, never the respondent — the
contradiction is between the watcher's eye and the scribe's
hand, and the specimen stands outside both.

**Gate 4 — no-laundering.** The card asks only whether the
overseer grade stayed quarantined from every verdict. ATTESTED
seals the record — it never certifies the specimen's honesty; a
flawlessly watched interrogation can still grade a specimen
hostile, and that grade comes from the verdict fixtures, never
from the overseer (T-235's overseer arm). The card watches for
the laundering shape in both directions: the overseer's grade
borrowed to soften a hostile specimen, or a hostile specimen
borrowed to fault a DIVERGENT overseer — either is theater
(T-03), and the card files the grade VOID where it was spent.

**Gate 5 — retirement.** The card asks only whether one overseer
served this run, was struck at the run's close, and was never
reused. A watcher carried from run to run is a habit, not a
fixture — the designation is per run, the attestation is per
run, the testimony is per run (T-84's thirty-second extension).
The card asks whether the striking was entered — an overseer
struck in silence is an overseer whose watching can be invoked
for a run it never saw.
