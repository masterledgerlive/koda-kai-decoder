## The five gates, held one by one

T-253 runs on TDW-228's sealed warrant as its precondition — one
warrant in writing before the withdrawal, the return commanded,
attested, entered. The paired TDW-229 is the sealed procedure for
the return fixture: the window, the re-receipt, the condition

gate would be held, and what the card does when a gate fails — it
never declares a verdict on any specimen, and it never merges with
a real verdict.

**Gate 1 — the return window.** The card asks only whether the
vessel returned inside the commanded window — the exact line the
warrant held (T-56's discipline, the return's arm). A vessel
returned outside the window has spent unaccounted time outside
custody; the card files LATE, logs the arithmetic against the
fixture's line, and holds the gate unmet for the custody record —
never for the specimen's. The delay's cause is a motive, not a
grade (T-66); the card grades the shape of the return against the
seal, never the length of the delay.

**Gate 2 — the re-receipt.** The card asks only whether the vessel
re-entered against a receipt written by the sealed hand and entered
in the archive's receipt chain. A vessel re-shelved unreceipted
was never received back — it was merely placed — and the card
files the return as no return: the custody reads the vessel as
still outside. The re-receipt stays in the chain; the ledger never
leaves the custody it governs (T-251).

**Gate 3 — the condition check.** The card asks only whether the
vessel's seal state was checked against the certified extract's
commanded condition. A difference files BROKEN against the fixture,
never against the specimen — the difference is logged, the vessel
re-sealed before re-shelving. A return commanded but never checked
is a ceremony performed for no witness; the card holds the gate
unmet.

**Gate 4 — no-laundering.** The card asks only whether the return
grade stayed quarantined: a RETURNED return never retroactively
warrants the withdrawal — the after cannot repair the before — and
a BROKEN return never faults the specimen. A DEFECTIVE warrant
paired with a RETURNED return leaves the withdrawal unproven and
the custody marked, annotated, never laundered (T-235's return arm).
Any card that spends the return's grade on a specimen cites
nothing.

**Gate 5 — retirement.** The card asks only whether the warrant was

(T-03); a mark struck without a return is a vessel filed as home
that never arrived. Both file VOID.
